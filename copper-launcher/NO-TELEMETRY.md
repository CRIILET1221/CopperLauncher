# Исходники без телеметрии

Основа: архив ветки main https://github.com/millida/launcher, скачанный 12 октября 2026.

Удалены очередь событий, идентификатор установки, сбор железа для отправки,
аналитика кликов и показов, отчёты о производительности, автоматическая отправка
ошибок и вылетов, сигналы совместимости модов, heartbeat с игровой активностью,
отправка наигранного времени, история поведения для рекомендаций.
Старая очередь и идентификаторы удаляются при открытии интерфейса.
Встроенный мод Millida отключён; его файлы удаляются перед запуском.
Автообновление до официальных сборок и автоматическая переустановка отключены.
Локальные логи, диагностика и локальный счётчик игрового времени сохранены.

Вход Millida, магазин, каталог, друзья и другие функциональные обращения к их
сервисам ещё присутствуют. Эта правка удаляет телеметрию, а не всю интеграцию
с Millida. Косметика встроенного мода и публикация активности друзьям отключены.
Discord Rich Presence остаётся отдельной пользовательской настройкой.
Обращение в поддержку отправляется только по явному действию пользователя.

Проверка TypeScript прошла. Установщик и Rust-ядро не собирались по просьбе
пользователя. Проверка запуска игры остаётся для самостоятельной сборки.

## Собрать Windows-установщик

Нужны Bun, Rust и Visual Studio Build Tools с C++ (подробнее BUILDING.md).
Из распакованной папки launcher-main:

```powershell
bun install
bun run tauri build
```

Установщик: src-tauri\target\release\bundle\nsis\

Это изменённые исходники для собственной сборки, а не официальный релиз Millida.
