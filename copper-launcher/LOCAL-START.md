# Запуск без регистрации Millida

Лаунчер сразу открывает экран «Сборки», в том числе на чистом профиле.
Авторизация Millida и флаг прежнего входа больше не открывают и не закрывают
доступ к интерфейсу. Выход из последнего аккаунта оставляет библиотеку открытой.
Стартовая заставка и обязательный мастер знакомства убраны.

На экране сборок доступны «Войти через Microsoft» и «Аккаунты».
Во втором окне можно добавить Microsoft, Ely.by или локальный офлайн-аккаунт.
Millida убрана из списка добавления аккаунтов. Учётная запись Microsoft
использует существующий прямой путь Microsoft → Xbox → Minecraft Services.
Для публичного форка всё ещё нужна собственная регистрация Azure приложения
и MILLIDA_MS_CLIENT_ID; ключ приложения не является паролем пользователя.

Сервисы Millida (магазин, защищённые сборки и собственные серверы, друзья,
хостинг) пока остаются в коде и могут отдельно требовать их аккаунт.
Эта правка не превращает платные или закрытые сборки в бесплатные.
Предыдущие изменения удаления телеметрии сохранены.

Проверены типы TypeScript и поведение состояния интерфейса: чистый профиль,
выход из аккаунта и навигация. Windows-установщик не собирался.

Пересобрать из этой папки:

```powershell
bun run tauri build
```
